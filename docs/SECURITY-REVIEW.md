# Security review record

## Reviewed remote-backup delta · 2026-11-06

Focused source review covered the new destination, network, publication, retry, staging and restore boundaries. Profiles accept only selected `RIGSHELF_BACKUP_*` variable names; values never enter portable definitions, browser responses or receipts. Native S3 signing supplies every credential/endpoint option explicitly, including an empty unselected session token, and fixtures verify that an ambient AWS session token is not forwarded. Remote requests refuse redirects and bound time/response bytes. Malformed pointer, manifest and archive errors use fixed messages rather than response excerpts.

GitHub publication binds the reviewed repository identity/base, preserves the base tree and unrelated paths, rejects file/link/submodule prefix conflicts, and makes one commit/PR. Expected PR head/base and repository identity are rechecked before app merge; native GitHub protections remain authoritative. S3 checks conditional create/replacement, uploads immutable objects first and conditionally publishes the pointer last. Probe cleanup failure blocks publication and reports the exact temporary key. No remote archive/branch pruning is performed.

Review fingerprints, expiry, private destination exclusion and persistent operation receipts protect stale or duplicate publication. Retry rechecks terminal state inside the database reservation, so a late retry cannot reset a concurrently completed receipt. Status updates use sequence checks. Restart/ambiguous outcomes preserve the frozen staged artifact; archive, manifest and canonical pointer identity are checked before retry. Cancellation and shutdown drain owned jobs before catalog closure.

Restore validates exact archived hashes and portable format before preview and again before import. Default restore preserves local-only/authored records; explicit Preset/directive replacement still refuses immutable conflicts and checks current local content and destination. Import validation and writes now share one SQLite reservation, closing a concurrent-authored-definition overwrite gap. Restore cannot grant ownership, project automation, access keys or project writes. MCP cannot create or reroute backup destinations; publication/restore/merge require the writable tool and explicit reviewed IDs.

Normal protocol, concurrency, HTTP/CLI/MCP and Chromium regressions exercise these controls. This is a focused source/lifecycle review with ordinary development tests, not a new independent full-codebase audit, a qualified exploit reproduction or live provider certification. The formal audit below retains its recorded sandbox limitations. The 2026-11-06 `bun audit` query reported no known advisories across 255 checked packages; that does not establish content safety. Real-account checks remain pending the user’s chosen repository/bucket and credentials.

Earlier delta sections are historical; their local-export-only limitations are superseded by the remote-backup implementation above.
