# Naming decision

Working product name: **Kitfold**; command: `kitfold`.

The product folds a focused kit into a project: skills, MCP connections, and instructions. It describes the setup action rather than a backup service or a public skill marketplace. The name is short enough for a CLI, extends beyond skills alone, and does not depend on a particular agent.

Candidates considered: Skillsetup (too narrow), Strata (too abstract and crowded), Kitlane (existing developer tooling), Kitloom (existing AI-enabled CMS), Kitscope (existing software), Kitted (existing MCP product), and Kitrail (existing registered product name). A web search found no clear overlapping developer product for Kitfold, but this is not a trademark or domain-availability guarantee. No package, domain, repository, or external account was registered.

The name is deliberately replaceable. The data format has a numeric version; branding does not define the schema contract.
